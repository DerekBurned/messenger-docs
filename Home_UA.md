# Messenger documentation - Головна

Карта змісту (map of content) для Android-застосунку Messenger. Кожну нотатку звірено з реальним
кодом репозиторію застосунку (окремого приватного репозиторію; це сховище не містить коду
застосунку) на релізі 0.2.2.4, коміт `d6374fb`, 2026-11-11 (кореневий пакет
`com.example.messenger`, єдиний модуль `:app` плюс Cloud Functions у `functions/` у корені
репозиторію). Посилання на код подано як `path:line` відносно
`app/src/main/java/com/example/messenger/`, якщо нотатка не каже інакше; шляхи від кореня
репозиторію, як-от `functions/src/index.ts`, `firestore.rules` чи `gradle/libs.versions.toml`,
подано як є. На інші нотатки - вікі-посилання.

Це сховище документує код, який існує, а не той, що уявляє специфікація. Коли обґрунтування не
вдалося відновити з коду чи історії, нотатка прямо про це каже, а не вигадує його.

## Що це за застосунок

Месенджер один-на-один (назва в лаунчері "Switch", поточний реліз 0.2.2.4, versionCode 20204,
ліцензія AGPL-3.0-only): автентифікація за номером телефону, що відхиляє невідповідність
реєстрації/входу, обмін текстом і медіа в реальному часі зі свайпом для відповіді, голосові
повідомлення та круглі відеонотатки, профіль чату зі спільними медіа, голосові та відеодзвінки,
індикатори присутності й набору тексту, локальне сховище за принципом offline-first, push-сповіщення
з вбудованою відповіддю та бульбашками розмов, видалення акаунта й наскрізне шифрування з кодом
відновлення та резервною копією ключів кількох епох. Від 0.1.13.1 також з'явилися віддалені
перемикачі функцій (Firebase Remote Config, що застосовуються у ViewModel і сервісі дзвінків),
Crashlytics і конвеєр GitHub Actions із порогом покриття. Kotlin, Jetpack Compose UI, презентація
за MVI, Hilt DI, локальне сховище ObjectBox, бекенд Firebase (Firestore + Realtime Database + Auth +
Storage + Cloud Messaging + Functions + Remote Config + Crashlytics), Agora RTC для дзвінків.

## Архітектура

- [[Architecture Overview_UA|Огляд архітектури]] - три шари, компонування модуля, граф
  залежностей, як повідомлення проходить наскрізно, і зв'язування під час запуску застосунку.
- [[Presentation Layer (MVI)_UA|Шар представлення (MVI)]] - контракт MVI (State / Intent /
  Effect), базовий клас `MviViewModel`, два стилі ViewModel, що реально є в коді, поділ на
  Root/Screen composable, і як UI збирає стан та події.
- [[Domain Layer_UA|Доменний шар]] - use case як викликні класи, інтерфейси репозиторіїв,
  інтерфейси сервісів і доменні моделі.
- [[Data Layer_UA|Шар даних]] - репозиторії, сховище ObjectBox, сервіси Firebase, DTO та
  маппери, черга офлайн-синхронізації, передавання й кешування медіа.
- [[Dependency Injection (Hilt)_UA|Впровадження залежностей (Hilt)]] - набір модулів, `@Binds`
  проти `@Provides`, скоупи, і ручний `EntryPoint`, що використовується з компонентів, які
  створює фреймворк.
- [[Async and Reactivity_UA|Асинхронність і реактивність]] - Flow проти StateFlow проти
  SharedFlow, мости `callbackFlow`, вибір диспетчера та scope - з реальним місцем виклику для
  кожного.
- [[Navigation_UA|Навігація]] - шлюз сесії (`SessionState`), шлюз готовності шифрування, типізовані
  маршрути Navigation 3, стек навігації `NavDisplay`, і як навігаційні аргументи потрапляють у
  `SavedStateHandle` ViewModel.
- [[Feature Flags and Remote Config_UA|Feature flag-и та Remote Config]] - як оголошуються 62 feature
  flag-и, обчислюються з Firebase Remote Config і списку "вимкнено за замовчуванням" збірки,
  читаються UI, застосовуються у ViewModel та в коді дзвінків і сповіщень і передаються в Crashlytics.

Плани, пропозиції й історія (кожна нотатка починається зі статусу, перевіреного на 0.2.2.4;
англійською):

- [[Multi-Device Encryption (Research)]] - Partial. Як зберегти E2EE на кількох пристроях одночасно:
  виправлення розгалуження, push-токени для кожного пристрою й набір ключів кількох епох виходили;
  прив'язка через QR, екран пов'язаних пристроїв і відкликання - ні.
- [[Test Coverage - Implementation Plan]] - Done. План від 2026-10-21 для інтеграційних тестів,
  тестів ViewModel і екранів та порогу покриття Kover.
- [[Paging 3 Integration (Design)]] - Reverted. Paging 3 вийшов 2026-07-25 і був відкочений
  2026-07-28; списки знову звичайні реактивні Flow.
- [[File Layout Refactor (refactor-readability)]] і [[File Layout Refactor - Implementation Plan]] -
  Done. Рефакторинг "одна тема на файл" від 2026-08-11 - 2026-08-16 і другий прохід розкладки
  2026-10-18; розділення `CallForegroundService.kt` залишилося невиконаним.

## Функції

- [[Authentication_UA|Автентифікація]] - вхід за номером телефону з OTP, шлюз сесії, прив'язка
  акаунта, ініціалізація сесії й відновлення історії, чистий вихід.
- [[Conversations List_UA|Список розмов]] - список чатів, offline-first потік, присутність та
  аватари по учасниках, видалення для себе проти видалення для всіх.
- [[Search and Suggestions_UA|Пошук і підказки]] - анімація розгортання поля пошуку в таб-барі,
  закриття жестом "назад" і підказки-результати "Нещодавно шукані" / "Нещодавно відкриті" на базі
  сховища нещодавніх контактів.
- [[Chat and Messaging_UA|Чат і обмін повідомленнями]] - надсилання/отримання, відповіді,
  медіа-вкладення, підтвердження прочитання, пагінація, правила видалення повідомлень, видалені
  співрозмовники.
- [[Voice Messages_UA|Голосові повідомлення]] - запис із затисканням, доріжкою блокування змахом
  угору і змахом для скасування, перемикання голос/відео дотиком, жива хвиля зліва направо в шкалі
  децибелів з нормалізацією за піком, чернетки при перериванні, стійкий до збоїв outbox,
  зашифроване вивантаження, відтворення ExoPlayer з автопереходом і міні-плеєр.
- [[Video Messages_UA|Відеоповідомлення]] - круглі відеонотатки: запис фронтальною камерою через
  CameraX з круглим прев'ю, рішення надіслати/чернетка/видалити на `Finalize`, відеочернетки й
  кругла бульбашка з вбудованим відтворенням і перемотуванням уздовж краю.
- [[Chat Profile and Shared Media_UA|Профіль чату та спільні медіа]] - екран профілю співрозмовника
  і його вкладки спільних медіа (PR #54) за прапорцем `partner_profile_shared_media`.
- [[Calls (Voice and Video)_UA|Дзвінки (голос і відео)]] - Agora RTC, машина станів дзвінка у
  foreground-сервісі, панель активного дзвінка з жестами свайп/бульбашка/повернення, PiP-відео,
  увімкнений екран і затемнення від датчика наближення, історія дзвінків.
- [[Presence and Typing_UA|Присутність і набір тексту]] - присутність online/away/offline та
  індикатори набору поверх Realtime Database.
- [[Notifications_UA|Сповіщення]] - обробка FCM, офлайн-збереження повідомлень, MessagingStyle,
  ярлики й бульбашки розмов, вбудована відповідь.
- [[Settings_UA|Налаштування]] - екрани налаштувань, збережена в DataStore тема оформлення і
  видалення акаунта.
- [[End-to-End Encryption_UA|Наскрізне шифрування]] - шифрування повідомлень X25519 + HKDF +
  AES-GCM, реєстр ключів, ротація епох, safety numbers.
- [[Appearance and Theming_UA|Вигляд і теми]] - режим теми світла/темна/системна, градієнтні та
  імпортовані шпалери, інтенсивність фону, шар токенів дизайну, багаторазові модифікатори анімації
  і набір тестів контрасту WCAG.

Кожна нотатка функції має companion-нотатки: `- Code` (реальний код), `- Explained Simply` (просте
пояснення) і `- Basic Example` (успадкований базовий приклад), а також секцію `## Visualization` зі
схемою Mermaid. Для голосових повідомлень це [[Voice Messages - Code]],
[[Voice Messages - Explained Simply]] і [[Voice Messages - Basic Example]] (англійською); для
відеоповідомлень - [[Video Messages - Code]], [[Video Messages - Explained Simply]] і
[[Video Messages - Basic Example]] (англійською). Для профілю чату та спільних медіа -
[[Chat Profile and Shared Media - Code]], [[Chat Profile and Shared Media - Explained Simply]] і
[[Chat Profile and Shared Media - Basic Example]] (англійською).

## Домовленості цього сховища

- Нотатки з чотирьох частин там, де йдеться про технологічне рішення: Що / Як ми це
  використовуємо / Чому саме так / Які альтернативи розглядали.
- Пояснення функцій спершу називають мету (навіщо ця сигнатура, навіщо цей Flow, навіщо цей
  scope), а вже потім проходять по механіці.
- Без емодзі. Абсолютні дати. `path:line` для коду, вікі-посилання між нотатками.
